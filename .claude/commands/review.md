description: Ревью текущей ветки или PR llm-arch-research — CI локально, сверка с первоисточниками, соглашения проекта
argument-hint: [номер PR или фокус ревью]
---
Контекст: $ARGUMENTS

1. Diff: `git diff master...HEAD` плюс незакоммиченное; для PR — `gh pr view`/`gh pr diff` (переключение ветки — только с согласия пользователя). Найди связанный план, ADR или пункт бэклога.
2. Параллельно: **check-runner** (по затронутым путям), **code-reviewer**, **paper-reviewer** (если затронуты `llm/src`, главы пособия или обучение).
3. Если в diff есть исправление ошибки — **verification-engineer** проверяет, что регрессионный тест падает на старом коде (после check-runner, когда никто не правит файлы).
4. Покажи пользователю: таблицу проверок, вердикты, сводный список замечаний (сначала BLOCKER и P1), кандидатов в бэклог.

Ничего не исправляй без просьбы.
