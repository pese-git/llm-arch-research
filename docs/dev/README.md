Этот раздел — для тех, кто развивает сам проект: исправляет ошибки, добавляет модели и блоки, пишет документацию. Как пользоваться библиотекой — в [Руководстве пользователя](../guide/README.md), как устроены архитектуры — в [Учебном пособии](../textbook/README.md).

**Главный принцип проекта.** Код учебный, но его результат проверяется: блоки небольшие и читаются целиком, а модели сверяются с эталоном — с HuggingFace на тех же весах, с наивными реализациями формул, со статьями. Изменение, которое меняет выход модели, должно быть подтверждено тестом, а расхождение с оригиналом — задокументировано.
